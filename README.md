# Rechercher un nombre tiré au sort

A Java EE web application where the user tries to find a number randomly drawn by the server, as practical work for an ENI course.

## About The Project

Practical work for the ENI course "Le développement Web côté serveur - BackEnd avec Java Enterprise Edition (JEE)" (Module 2 - Les servlets). The original assignments (in French) are available in the repository: [Module 02 - Enoncés TP](https://github.com/Dyrits/RECHERCHER-UN-NOMBRE-TIRE-AU-SORT/tree/master/Module%2002%20-%20Enonc%C3%A9s%20TP).

From the assignments: the user must find a number drawn at random by the server (between 0 and 10 in the first version), with an unlimited number of attempts. The application is made of a static form, a servlet processing the guesses, and static pages reporting success or failure. The second version lets the administrator customize the bounds of the draw through initialization parameters.

From the author's notes: the project was built from scratch following specific instructions; the application was renamed "FindTheNumber" (from the assigned name TPRechercherNombre), and because the first version validated the user's input in the HTML form, the maximum value was extended to 1000 without giving the user any hint about the range.
